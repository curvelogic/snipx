All notable changes to snipx are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Added

- Initial reference implementation of the SnipX v0 language: lossless
  parser for commentaria, marginalia, and intralinea; conservative
  formatter; statement expansion; plain and Markdown visible-text
  extraction; snippet resolution; canonical JSON export; and the
  `snipx` CLI (`check`, `resolve`, `export`, `fmt`).
